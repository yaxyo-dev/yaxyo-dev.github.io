Yamakasi Barbershop

A one-page site with one job: get a customer from their phone into the barber’s chair.

The job of this page

People look for a barber on their phone, usually in a hurry. They want to know what it costs, where it is and how to get a slot. So the page opens on the name and a single booking button, then goes straight to prices, examples of the work and the address.

The look

Black walls, cream type and a barber-pole stripe drawn entirely in CSS. The price list uses dotted leaders, like a menu printed for the shop window, and Bebas Neue gives the name poster weight on a narrow screen.

How it’s built

One HTML file under 5 KB with the CSS inside it. There’s no framework and no build step, so it can be hosted anywhere and edited by hand.

What’s still a placeholder

Prices and photos stay blank until the shop supplies real ones. A banner at the top of the page says so, instead of inventing them.
