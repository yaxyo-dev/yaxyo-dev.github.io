Telegram assistant

Mijoz Bot

A Telegram assistant that answers my customers in my name and knows when to stop talking.

How a message moves

  1. A customer writes to my Telegram Business account.
  2. If I’ve written in that chat in the last 12 hours, the bot stays silent.
  3. Otherwise Gemini drafts a reply from the last 20 messages and my rules, in the customer’s own language.
  4. The reply goes out in my name.
  5. If the customer agrees, asks about payment or a meeting, complains or asks something odd, the model adds a hidden tag to its reply.
  6. The bot strips the tag, goes quiet in that chat for 48 hours and sends me the last message.

The problem

Customers ask about websites at all hours, and most of the questions are the same: price, timing, what’s included. A fast answer often wins the job, but an AI should never be the one to close a deal.

A human always outranks the bot

Anything I type in a chat silences the bot there for 12 hours. It never talks over me.

When it fails, it says nothing

If the AI call fails, the customer doesn’t get a broken reply. I get an alert with their message and answer myself.

Rules live in a text file

Prices, timing and rules are in one plain text file that’s read before every reply. I can change them in Notepad without touching code or restarting anything.

It doesn’t make things up

The rules forbid inventing prices or promising discounts. If it doesn’t know something, it says it will find out. If someone asks whether it’s a bot, it says an assistant is answering and hands the chat to me.

Limits

It runs on my own computer, so it only works while that’s switched on. It can make mistakes, so customer chats still need a daily check. On Gemini’s free tier, Google may use conversations to improve its services.
